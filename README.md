# Decision Intelligence Dashboard

This repository contains **Decision** — a Decision Intelligence Dashboard that helps teams understand why decisions were made, what trade-offs were involved, and how those decisions impacted outcomes.

## Quick start

The application lives in the `Decision` folder:

```bash
cd Decision
npm install
npm start
```

Then open **http://localhost:4200**.

For full documentation (what Decision is, architecture, how to run, roadmap), see **[Decision/README.md](Decision/README.md)**.
