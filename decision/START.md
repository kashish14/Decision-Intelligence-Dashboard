# Start Decision

From a terminal, run (use the full path so `cd` works from anywhere):

```bash
cd "/Users/kashishagarwal/Documents/Personal Projects/Decision Intelligence Dashboard/decision"
nvm use 20
rm -rf node_modules package-lock.json
npm install
npm start
```

Then open **http://localhost:4200**.

If you're already in `Decision Intelligence Dashboard`, use:

```bash
cd decision
nvm use 20
npm install
npm start
```
